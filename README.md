# Alchemy Dash: Overdrive

ALCHEMY DASH: OVERDRIVE
Offline Java arcade shooter. Requires Java 17 or newer.

1. Extract the ZIP.
2. Open the extracted folder (the one containing AlchemyDashV2.java).
3. Click the File Explorer address bar, type cmd, and press Enter.
4. Run: java AlchemyDashV2.java

ENTER start/restart. WASD or arrow keys move. Hold SPACE to shoot. P pauses.
Shoot enemies, build combos and survive rising waves. Collect S for shield,
R for rapid fire, and + for an extra life. No account or internet required.
