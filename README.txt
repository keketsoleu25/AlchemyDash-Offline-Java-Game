ALCHEMY DASH — OFFLINE JAVA GAME

Requirements: Java 17 or newer on Windows, macOS, or Linux.
No internet, libraries, account, or installation is needed after Java is installed.

RUN
1. Unzip this folder.
2. Open a terminal in the folder with AlchemyDash.java.
3. Run: java AlchemyDash.java

On Windows, you can open the folder in File Explorer, click the address bar,
type cmd, press Enter, and run the command above.

PLAY
Enter: start or restart
Left/Right arrows or A/D: move
Move mouse: steer
P: pause or resume
Collect green crystals for points; dodge red rocks. You have three lives.
The best score is saved locally using Java Preferences.

CHECK
Run: java AlchemyDash.java --self-test

Source is included so you can change the colors, rules, art, and difficulty.
